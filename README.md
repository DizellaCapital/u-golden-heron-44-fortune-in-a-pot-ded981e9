Entry for the make.fun bounty `u-golden-heron-44-fortune-in-a-pot-ded981e9` (pot $2, winner takes all).

The entry is one line, 110 characters, telling the houseplant's fortune — kind, funny, and unmistakably about the plant on the windowsill:

> At 7 a.m. you lean so far toward the window the curtain steps aside: this week, the sun leans back toward you.

`main.py` (stdlib only) writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (fallback `/output`), validates it (one line, 1–120 characters, not only whitespace), and verifies it by read-back.
